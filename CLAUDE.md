# grassiportal — instruções para o Claude Code

- Projeto simples: HTML + CSS + JavaScript puro em `site/`. Sem framework, sem build, sem npm.
- O backlog vive nas issues do GitHub (grassi21-cloud/grassiportal, board Projetos_Grassi); cada issue tem a spec
  e uma seção "Claude Code prompt". "Implementa a P001" = seguir o prompt da issue #1 (mapa em `docs/backlog/README.md`).
  `docs/backlog/` guarda só cópias exportadas, não editar à mão.
- Antes de escrever código, resumir o que vai fazer e pedir confirmação ao André.
- Nunca fazer push. Commit só quando o prompt pedir.
- Textos da interface em português. Funcionar bem no celular (375 px) e em tela larga.
- Nada de segredos nos arquivos de `site/` (tudo ali é público para quem abre a página).
- Arquivos com fim de linha LF.
